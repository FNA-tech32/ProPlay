## 🌟 Introduction

**Pro Play** is a full-service digital agency dedicated to designing, developing, and scaling high-performance digital products for startups, enterprises, and visionary brands. From high-conversion landing pages to complex web platforms, native mobile applications, and immersive AR/VR environments, Pro Play combines creative design thinking with cutting-edge engineering.

- **Purpose & Precision**: Every interface is designed with a mobile-first philosophy, fluid interactions, and conversion-optimized architecture.
- **Enterprise Scalability**: Powered by React 19, Vite, and Tailwind CSS 4 to guarantee ultra-fast load times and seamless responsiveness.
- **Full Digital Lifecycle**: End-to-end support covering UI/UX design, custom frontend development, search engine visibility (SEO), and post-launch maintenance.

## 🚀 Key Features

- **⚡ Blazing Fast Single Page Experience**: Instant route transitions and zero lag powered by Vite and React Router 7.
- **📱 100% Responsive & Mobile-First**: Pixel-perfect layout across mobile smartphones, tablets, laptops, and ultra-wide desktop monitors.
- **🧭 Dynamic Navigation System**: Fixed top header with active states, branded typography, and collapsible mobile drawer.
- **💼 Interactive Contact & Inquiry Hub**: Direct form with client-side state handling, field validation, service preference selection, and real-time confirmation messaging.
- **📰 Industry Insights Blog**: Dynamic category tagging, article search field, highlighted feature stories, and author cards.
- **📊 Metric Counters & Social Proof**: Live metric display (Countries, Projects, Transactions, Happy Customers) and brand partnership showcases.
- **💌 Newsletter Subscription**: Accessible subscription module built directly into the page workflow.

## 📑 Pages & Component Architecture

### Pages (`src/pages/`)
- **`Home.jsx`**: Hero showcase, 4-tier service highlights, feature spotlight cards (Mobile, Web, AR/VR), company partnership logos, and newsletter banner.
- **`About.jsx`**: Brand story, creative mission statement, service breakdown cards, and visual collage.
- **`Services.jsx`**: Detailed service overview, feature comparison grid, metric impact stats (81+ Projects, 7M+ Transactions, 6000+ Customers), and CTA.
- **`Blog.jsx`**: Industry insights, category filters (`UI/UX Design`, `Web Development`, `Digital Marketing`, `AI & Automation`), article search, and featured post layout.
- **`Contact.jsx`**: Dual-tier primary/alternative contact cards, interactive inquiry form with instant submission feedback, Google Map visual, and direct links.

### Components (`src/components/`)
- **`Navbar.jsx`**: Responsive navigation bar with brand badge and hamburger mobile drawer.
- **`Hero.jsx`**: Eye-catching hero section with direct CTA buttons and vector illustration.
- **`Footer.jsx`**: Multi-column footer containing quick links, primary/alternative contact details, business hours, and social media icons.
- **`Newsletter.jsx`**: Lead capture newsletter subscription card.
- **`TextCard.jsx`**: Reusable typography and layout card with customizable styling.
- **`ScrollToTop.jsx`**: Automatic scroll restoration upon page route change.

## 💻 Getting Started & Local Setup

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18.0 or higher recommended)
- [npm](https://www.npmjs.com/) (version 9.0 or higher)

### 1. Clone or Open the Repository
```bash
git clone https://github.com/Shubh2268/Digital-Web-Agency.git
cd ProPlay
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:5173` to see the live application.

## 📦 Build & Deployment

### Production Build
To create an optimized production bundle:
```bash
npm run build
```
The compiled output will be generated inside the `dist/` directory.

### Preview Production Build
To test the production build locally before deployment:
```bash
npm run preview
```

### Linting
To check and enforce code standards:
```bash
npm run lint
```
